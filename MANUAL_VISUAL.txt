│ 🐛 TROUBLESHOOTING                                                │
└────────────────────────────────────────────────────────────────────┘

  ¿resetData() no funciona?
  → Recarga la página (F5) y abre consola de nuevo

  ¿Las alertas no aparecen?
  → Navega a la sección de Alertas después del reset
  → Espera 2-3 segundos para que se carguen

  ¿Los gráficos están vacíos?
  → Los datos de asistencia están cargados correctamente
  → Verifica que las gráficas se estén renderizando
  → Abre la consola (F12) para ver si hay errores
